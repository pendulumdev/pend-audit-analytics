Search Console and GA4 analytics CLI. Node 22.12 floor and commander / google-auth majors for v0.2.0.

**Min version support:**
- Node.js **22.12.0**

**Requires:**
- A Google service account with Restricted / Viewer access to Search Console and/or GA4

**Runtime support:**
- macOS
- Linux

**Changes since v0.1.1:**
- Raise the Node floor to 22.12 so commander 15 and google-auth-library 11 install under engine-strict
- Biome 2.5.10
- README intro, GA4 and Search Console badges
- Remotes and install URLs pointed at pend-audit-analytics
